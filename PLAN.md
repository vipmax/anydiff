# AnyDiff: Сверхбыстрый мультибуфферный редактор Diff & Code Review на Swift для macOS

Нативное macOS-приложение на Swift, реализующее **MultiBuffer Diff Code Reviewer & Editor** по архитектуре Zed (`~/dev/tmp/zed/crates/multi_buffer`).

## Архитектура и принципы работы

В Zed мультибуффер объединяет множество срезов файлов (excerpts) из разных файлов в единый виртуальный документ с общим скроллом, быстрой трансляцией координат, точной нумерацией строк и **полноценным живым редактированием**.

```
┌────────────────────────────────────────────────────────┐
│ MultiBuffer (Единый виртуальный документ)              │
│                                                        │
│ ┌────────────────────────────────────────────────────┐ │
│ │ Excerpt 0: Sources/Core/Engine.swift (Строки 14-38)│ │
│ │  - Заголовок файла & статистика диффа (+12, -4)    │ │
│ │  - Старый №  Новый №  [Код с синтаксисом & word diff│ │
│ │  - ✍️ Живое редактирование (ввод, удаление, undo) │ │
│ └────────────────────────────────────────────────────┘ │
│ ┌────────────────────────────────────────────────────┐ │
│ │ Excerpt 1: Sources/UI/Editor.swift (Строки 90-120) │ │
│ │  - Заголовок файла & статистика диффа (+25, -2)    │ │
│ │  - Блок инлайн-комментария код-ревью               │ │
│ └────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────┘
                           │
                 DisplayMap & Layout
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│ Custom MultiBuffer Editor View (CoreText движок)       │
│  - Виртуализация вьюпорта (120 FPS ProMotion)          │
│  - Двойной гаттер (Старый № / Новый № / Статус + - ~)  │
│  - Пословный дифф (Intra-line word diff)               │
│  - Интерактивное раскрытие контекста (+5, +10, все)    │
│  - Полноценное редактирование: курсоры, ввод, Undo     │
│  - Добавление инлайн комментариев для ревью            │
└────────────────────────────────────────────────────────┘
```

## Основные компоненты системы

### 1. MultiBuffer Core (`Sources/AnyDiffCore/MultiBuffer/`)
- **`Buffer`**: Высокопроизводительный буфер текста с индексацией строк, байтовыми смещениями UTF-8 и точками `(строка, колонка)`.
- **`Excerpt`**: Срез конкретного файла (`Range<BufferRow>`), содержащий метаданные файла, статус изменений, границы контекста и состояние сворачивания.
- **`MultiBuffer`**: Агрегирует срезы в единое виртуальное пространство координат (`MultiBufferRow`, `MultiBufferOffset`).
  - Быстрый маппинг координат: `MultiBufferRow <-> (ExcerptIndex, BufferRow)`.
  - Динамическое расширение/сжатие строк контекста (раскрыть 10 строк вверх/вниз, раскрыть весь файл).
  - Поддержка транзакций редактирования: вставка, удаление, замена текста с синхронизацией буферов.
- **`DiffHunk` & `WordDiffEngine`**: Обработка ханков диффа и пословное/посимвольное сравнение изменений внутри строк (LCS/Myers diff).

### 2. Подсистема живого редактирования (`Sources/AnyDiffCore/Editing/`)
- **`TextEditTransaction`**: Атомарные правки текста в срезах с сохранением истории.
- **`UndoManager`**: Полноценный Undo/Redo для правок в мультибуффере (как в Zed `History`).
- **Синхронизация буферов**: При редактировании строки в срезе, смещения остальных строк и границы ханков автоматически обновляются без задержек.
- **Сохранение файлов**: Возможность сохранить отредактированные файлы обратно на диск или в git working tree.

### 3. Парсер Diff и система ревью (`Sources/AnyDiffCore/Diff/`)
- **`GitDiffParser`**: Парсинг unified diff (`git diff`, GitHub/GitLab PR diffs, `.patch` файлы).
- **`ReviewManager`**: Управление комментариями ревью к конкретным строкам, решениями по ревью (Approve / Request Changes) и чекбоксами проверенных файлов.

### 4. DisplayMap и виртуализация рендеринга (`Sources/AnyDiffCore/Display/`)
- **`DisplayMap`**: Преобразует логический MultiBuffer в визуальные строки:
  - `ExcerptHeaderLine` (Имя файла, бейджи изменений, кнопки развернуть/свернуть, копирование пути).
  - `CodeLine` (Двойные номера строк: Старый № / Новый №, маркер `+`/`-`/`~`, подсвеченный синтаксис, прямоугольники пословного диффа).
  - `FoldGapLine` (`... 45 скрытых строк ... [Развернуть +10 вверх] [Развернуть +10 вниз]`).
  - `ReviewCommentLine` (Инлайн карточка треда комментариев).
- **`LineLayoutCache`**: Кэширование `CTLine` и типографики CoreText для отрисовки без лагов.

### 5. Кастомный редактор (`Sources/AnyDiffUI/Editor/`)
- **`CustomMultiBufferEditorView`**: Полностью кастомный `NSView` с прямой отрисовкой через CoreText / Quartz (без тяжеловесного `NSTextView`):
  - Виртуализация (рендерится только видимая область экрана + овердроу-буфер).
  - Плавный скролл 120Hz ProMotion.
  - Полноценное редактирование: мигающий курсор, ввод текста, Backspace, Delete, Enter, стрелки, выделение текста мышью и клавиатурой, Copy/Cut/Paste.
  - Прямой переход курсора между разными файлами и срезами.
  - Hover-эффекты и обработка кликов по кнопкам расширения контекста и добавления комментариев.
- **`GutterView`**: Кастомный гаттер с двойными номерами строк, цветными полосками изменений (зеленый `+`, красный `-`, синий `~`) и кнопкой `+` для комментирования при наведении.
- **`SyntaxHighlighter`**: Быстрый токенайзер и подсветка для Swift, Rust, TypeScript, Python, C/C++, Go, JSON, Markdown и др.
- **`Theme`**: Набор современных тем в стиле Zed (Zed Dark, Tokyo Night, One Dark Pro, GitHub Dark, Catppuccin).

### 6. Пользовательский интерфейс macOS (`Sources/AnyDiffUI/`)
- **Sidebar**: Список измененных файлов с бейджами `+N / -M`, фильтром/поиском, выбором коммитов и отметками «Просмотрено».
- **Toolbar**: 
  - Режимы отображения (Unified Multibuffer, Full File Context, Changed Hunks Only).
  - Настройка количества строк контекста (0, 3, 5, 10, все).
  - Выбор темы оформления и размера шрифта.
  - Кнопки решения по ревью («Approve», «Request Changes»).
  - Кнопка сохранения правок (Cmd+S).
- **Интеграция с Git и демо-данные**:
  - Встроенные реалистичные примеры PR (Swift-рефакторинг, Rust MultiBuffer, TypeScript фича).
  - Открытие локального Git-репозитория (`git diff`).
  - Загрузка и Drag & Drop `.diff` / `.patch` файлов.
  - Модальное окно для вставки произвольного diff-текста.

## План верификации

### Автоматические тесты (`swift test`)
1. Тестирование трансляции координат `MultiBuffer` (виртуальная строка <-> строка файла).
2. Тестирование редактирования в срезе и работы Undo/Redo.
3. Тестирование парсера `GitDiffParser` на сложных многофайловых патчах.
4. Тестирование пословного сравнения `WordDiffEngine`.
5. Тестирование `DisplayMap` и генерации корректных номеров строк (Old/New).

### Ручная проверка в приложении (`swift run AnyDiff`)
1. Проверка производительности скролла (120 FPS) на больших диффах (10+ файлов, тысячи строк).
2. Проверка живого редактирования кода в любом срезе с сохранением и отменой действий (Undo/Redo).
3. Проверка динамического раскрытия контекста (`+5 строк`, `+10 строк`, `Раскрыть весь файл`).
4. Проверка создания инлайн-комментариев по клику на `+` в гаттере.
5. Проверка переключения тем и режимов просмотра.
6. Проверка открытия локальных git-репозиториев и вставки произвольного diff.

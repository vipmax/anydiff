# Управление автоскроллом агентской панели

## Цель

Во время стриминга агент должен держать чат внизу только тогда, когда пользователь действительно следит за последними сообщениями. Если пользователь прокрутил историю вверх, новые токены не должны возвращать его в нижнюю часть чата.

## Разделение состояний

Не следует смешивать два разных понятия:

- `isNearBottom` — находится ли viewport визуально около нижней границы;
- `followOutput` — нужно ли автоматически прокручивать чат за новым выводом агента.

`onNearBottomChanged` должен обновлять состояние кнопки в SwiftUI, но не определять режим автоследования напрямую.

## Ожидаемое поведение

1. При первом открытии панели `followOutput = true`.
2. Пока `followOutput == true`, новые сообщения и токены стриминга прокручивают чат вниз.
3. Когда пользователь вручную прокручивает чат вверх, `followOutput` переключается в `false`.
4. При отключённом `followOutput` обновления сообщений не меняют позицию пользователя.
5. Когда пользователь сам возвращается к нижнему порогу, `followOutput` снова становится `true`.
6. Кнопка «К последним сообщениям» должна:
   - включить `followOutput`;
   - прокрутить чат вниз;
   - скрыться после достижения нижней границы.
7. Начало нового запроса пользователя может явно включать `followOutput`, чтобы новый ответ открывался с последних сообщений.
8. Раскрытие tool call или другой явный переход в режим инспекции должен временно выключать `followOutput`.

## Защита от ложных событий

Bounds-change события возникают как из-за действий пользователя, так и из-за программной прокрутки, layout и resize. Программную прокрутку нужно помечать отдельно, чтобы она не воспринималась как ручное действие:

```swift
private var followOutput = true
private var isProgrammaticScroll = false
```

Проверка нижней границы может выглядеть так:

```swift
private func handleBoundsChanged() {
    let nearBottom = isNearBottom

    if !isProgrammaticScroll {
        followOutput = nearBottom
    }

    onNearBottomChanged?(nearBottom)
}
```

При обновлении сообщений:

```swift
if followOutput {
    scrollToBottom(animated: !isStreaming)
}
```

При программной прокрутке флаг должен быть сброшен после завершения операции или animation completion:

```swift
isProgrammaticScroll = true
scrollToBottom(animated: true) {
    isProgrammaticScroll = false
}
```

## Что проверить тестами

- Пользователь прокрутил вверх во время стриминга — viewport не прыгает вниз.
- Новые токены не меняют позицию при `followOutput == false`.
- Возврат к нижнему порогу снова включает автоследование.
- Кнопка «К последним сообщениям» корректно включает режим и прокручивает чат.
- Resize окна сохраняет нижнюю привязку только при включённом `followOutput`.
- Программный `scrollToBottom` не отключает автоследование.
- Раскрытие tool call не приводит к возврату вниз при последующих обновлениях.
